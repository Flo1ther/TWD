# Tower Upgrade Asset Prompts

Use one consistent style for all three icons: hand-painted fantasy tower defense UI, readable at small HUD size, warm wood/bronze/stone frame compatibility, bright highlight, clean silhouette, centered object, transparent background, no text.

## Framed Upgrade Button Set

```text
Create a matched set of three complete fantasy tower defense upgrade button icons. Each asset must already include the ornate UI frame and the upgrade symbol inside it, as one finished sprite, not separate icon and frame layers. Output three separate 128x128 PNG assets with transparent background, identical canvas size, identical frame size, identical frame silhouette, and identical visual scale.

Style: colorful medieval mobile tower defense HUD, warm carved wood and bronze frame, subtle dark stone inset, small blue crystal studs in the same positions on every frame, polished painterly rendering, crisp dark outline, readable at 64x64 pixels. Match the existing game HUD: carved wood planks, bronze trim, blue gems, warm highlights, slight bevel, soft shadow. No text, no numbers, no labels, no cost ribbon.

Button 1: damage upgrade, centered red-orange impact burst with a heavy axe blade or cracked sword, small sparks.
Button 2: range upgrade, centered blue-green magical targeting ring expanding from a small tower silhouette.
Button 3: attack speed upgrade, centered golden arrows or cannon shots with motion trails and a subtle wind or clock motif.

Important consistency rules: the frame must occupy about 92 percent of the canvas width and 92 percent of the canvas height; the inner symbol must occupy about 54 percent of the canvas; leave consistent padding between symbol and frame; center every symbol optically; match lighting direction from upper left; keep all three symbols visually balanced in weight, brightness, and contrast. The three sprites should look like they came from the same UI sheet.
```

## Font Direction

Recommended UI font: **Cinzel SemiBold** for buttons and panel titles.

Fallback for longer table/body text: **Alegreya Sans SC Medium** or **Alegreya Sans Medium**.

Why: Cinzel gives the buttons a fantasy-medieval carved-sign feeling without becoming unreadable, while Alegreya keeps stats like damage, range, fire rate, costs, and wave summaries easier to scan in compact panels.
